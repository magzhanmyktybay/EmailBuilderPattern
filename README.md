# Builder Pattern — Email

This project demonstrates the **Builder Design Pattern** in Java using an `Email` object.

### Structure

* `Email` — Product
* `EmailBuilder` — Builder interface
* `EmailObjectBuilder` — creates an Email object
* `EmailPreviewBuilder` — creates a text preview
* `EmailDirector` — defines email configurations
* `Main` — Client

The project also demonstrates **Clean Code principles**, fluent API, immutability, validation, and programming to an interface.
